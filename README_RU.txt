Absolute RPG v1.7.4 TEST

УСТАНОВКА
1. Отключите предыдущую версию нашего RPG-мода, отдельные XP Redux и stage7i.
2. Оставьте включёнными Experience Framework 2.2c, MAC и MCM.
3. Установите Absolute RPG через MO2 и разместите ниже этих зависимостей.
4. В установщике выберите ровно один вариант магазинного питания: GAMMA/No Mags, CLIKRAD без анимаций или CLIKRAD с анимациями.
5. Absolute RPG должен побеждать конфликты изменённых файлов Framework
   и ii_identify.script. Интеграция рассчитана на предоставленную версию
   Immersive Identification 4.4.1 с адаптацией WD 0.9.2.
6. «Наблюдатель» доступен всегда. Без Immersive Identification его покупка
   не даёт эффекта; встроенный ii_identify.script не регистрирует обработчиков
   и не обращается к ресурсам II, если ii_config.script отсутствует.
   II и WD сюда не включены и устанавливаются отдельно.

ПДА → Launcher MAC → Навыки и опыт.
Требования перков настраиваются в разделе навыков через режим редактирования.

ПЕРК «СИМБИОЗ»
Один ранг: включает встроенную механику Artefact Limb Healing для BHS.
Отдельный оригинальный аддон отключите: он больше не требуется. Absolute RPG
должен побеждать конфликт zzzzz_cxv_bhs_artihealing_prototype.script.
BHS и артефакты GAMMA остаются частью вашей сборки; они сюда не включены.
Перк по умолчанию доступен с 1-го уровня; требование меняется в редакторе ПДА.
Время лечения — 75 секунд / суммарная сила, с учётом состояния и условий
артефактов; у горящего костра скорость удваивается. Подробности есть в описании.
Перстень использует исходное значение 0.4 до общего бонуса костра.
Исправлено определение условий Сердца: при наличии опубликованного
healthThreshold используется он, иначе формула текущего PBA GAMMA
0.22 + 0.03 * число Сердец на поясе. Это исправление неработавшей проверки
в исходном аддоне, а не обещание поддержки произвольных сторонних версий PBA.
Лечение не превышает максимум частей тела, выключается при сбросе перка,
отсутствии подходящих артефактов или совместимой BHS. Время загрузки карты
не превращается в мгновенное лечение. В самой игре версия ещё не проверена.

Artefact Limb Healing — ilrathCXV, Copyright (c) 2023, MIT.
Лицензия: licenses/Artefact_Limb_Healing_LICENSE.txt.

ИНТЕРФЕЙС ПДА
Исправлена ширина вкладки под область штатного ПДА. Список навыков и
описание перекомпонованы; фон использует поверхность вашей темы ПДА.
Убраны крупные декоративные панели Framework. Установите как полную
замену предыдущей версии Absolute RPG и полностью перезапустите игру.
Игровая проверка отображения на вашей сборке пока требуется.

НАСТРОЙКИ UI
В разделе UI убраны неиспользуемый выбор полноэкранных обоев и
декоративное изображение заголовка. Старое значение обоев сохраняется
в конфигурации для совместимости. Остальные настройки доступны.
Это тестовое исправление вылета: точная причина из присланного лога
не определяется, требуется проверка открытия раздела UI в игре.

ИСПРАВЛЕНИЕ ОБРАБОТЧИКОВ
В обработчиках урона «Одиночки»
сравнение game_object заменено на сравнение числовых ID. Это исправляет
ошибку No such operator [__eq] defined in class [game_object].

ПЕРЕЛИСТЫВАНИЕ РАНГОВ
Стрелки слева и справа от номера ранга в описании навыка кликабельны.
Они меняют только просматриваемый ранг. На первом ранге скрыта левая
стрелка, на максимальном — правая; у однорангового перка скрыты обе.

НАСТРОЙКИ ПО УМОЛЧАНИЮ
Встроены предоставленные настройки Framework и требования/шаги 65 навыков.
Максимальный уровень по умолчанию — 150, предел настройки — 300.
Существующий кэш общих настроек имеет приоритет; сброс возвращает новые
исходные значения. Требования навыков внесены в определения самих навыков.
Кэш пользовательских настроек в архив не включён.

СКРЫТИЕ НАВЫКОВ
Поиск и возврат в лаунчер убраны. Отметка «Скрыть» под выбранным навыком
убирает его из списка. «Показать скрытые» временно показывает такие навыки,
в том числе изученные; снимите отметку «Скрыть», чтобы вернуть навык.
Отметки сохраняются в конфигурации, приобретённые бонусы не отключаются.
Категории и исходные ограничения доступа Framework продолжают действовать.

СЛОТЫ ОСОБЕННОСТЕЙ
Настройки → Особенности → Открыть все 6 слотов особенностей.
По умолчанию включено. При выключении возвращаются исходные требования
престижа; особенности из вновь заблокированных слотов снимаются штатным
механизмом Framework сразу после применения настройки.

ИСПРАВЛЕНИЕ ЧТЕНИЯ ДЕФОЛТОВ
Для обычного INI используются штатные r_bool / r_float / r_string.
Исправлен вылет apply_defaults с отсутствующим методом r_value, а также
аналогичное чтение исходных настроек интерфейса.

КОЛИЧЕСТВО ЗАДАНИЙ
Настройки → Задания: «Число заданий от престижа».
По умолчанию выключено, используется ползунок «Заданий без престижа»:
от 1 до 12, исходное значение 4. При включении зависимости действует
исходная формула: престиж + 2, не меньше 2 и не больше 12.
Новый лимит применяется при следующем обновлении списка заданий.
Для немедленного пересоздания списка есть штатное принудительное обновление.
Количество ограничено числом доступных типов заданий. Сложность и награды
продолжают рассчитываться по исходным правилам Framework.

ИЗУЧЕНИЕ МЫШЬЮ
Вместо E используется кнопка «Изучить ранг N — удерживайте ЛКМ».
Контур постепенно замыкается по часовой стрелке. Время удержания берётся
из настройки задержки изучения навыков. Покупается один следующий ранг.
Отпускание ЛКМ, уход курсора, смена навыка и закрытие окна отменяют удержание.
Уровень персонажа, престиж, очки и условия навыка проверяются повторно
перед покупкой. Просмотр других рангов стрелками не меняет покупаемый ранг:
его номер указан прямо на кнопке.

МАГАЗИННОЕ ПИТАНИЕ
GAMMA/No Mags сохраняет механику, описание и требования навыка из v1.6.0.
Без Mags Redux или его модификации этот перк не даёт эффекта.
CLIKRAD: ранги на уровнях 7, 20, 33, 46, 59 (шаг 13, редактируется в ПДА).
Ранг 1: разрядка +33%, зарядка без бонуса.
Ранг 2: разрядка +50%, зарядка +20%.
Ранг 3: разрядка +66%, зарядка +44%.
Ранг 4: обе скорости +66%; костюм +1 малое и +1 среднее место.
Ранг 5: обе скорости +100%; костюм +1 место каждого размера.
Бонусы рангов итоговые. На 5-м ранге малое/среднее место остаётся +1.
Без надетого костюма бонус мест не действует. Вместимость магазинов не меняется.
Бонусы совместимы с дополнительными местами подсумков/рюкзака и снимаются
при сбросе перка или снятии костюма через штатный пересчёт GMR.
Ускорение умножает исходную скорость MCM. +100% = половина времени.
В AML предел ползунка MCM 0.5–2.0 сохраняется для базовой скорости;
бонус перка применяется после него и не теряется при базе x2.
Вариант без анимаций не предназначен для активного AML.
Сторонние магазинные моды не включены: они устанавливаются отдельно.
Для ручной установки скопируйте gamedata, затем gamedata выбранной папки
variants поверх. Для GAMMA дополнительные файлы не нужны.
После смены варианта полностью переустановите Absolute RPG и перезапустите игру.
Приоритет Absolute RPG должен быть выше модов, чьи файлы он изменяет.

GMR fork — AndTheHeroIs & Priler; AML — SkyKi; Dynamic Reload Speeds — Verdatim.

ПЕРК «ЕГЕРЬ»
Один ранг, по умолчанию с 15-го уровня. Скорость анимации разделки ×2.
Работает с модулем разделки FDDA Redone (liz_fdda_redone_mutant_skinning / lam2).
FDDA Redone устанавливается отдельно. Без него перк виден, но не даёт эффекта.
Классический FDDA этой интеграцией не поддерживается.
Механизм ускорения и синхронизации звука адаптирован из
Dorn's Faster Skinning 0.9.0 — Dorn, предоставленного пользователем.
Отдельный Dorn's Faster Skinning отключите: его постоянные ускорения
могут складываться с перком. Встроенный перк не требует оригинала Dorn.
Ускоряется действие разделки; последующая анимация подбора не удаляется.
Количество добычи и требования к ножу определяет исходная система.
Фактический износ ножа при разделке уменьшается на 50%: исходная функция
вызывается один раз, затем возвращается половина реально потерянного состояния.
Учитываются вызовы из окна добычи и завершения анимации FDDA Redone.
Износ от ножевых ударов и других действий не изменяется.
При сбросе навыка новые действия используют обычную скорость.
Изменение входит во все три варианта установки. Проверка в игре требуется.

Ранги 1–5 и их эффекты сохранены. Первый ранг с 5-го уровня, шаг 8.
Ранг 6 (уровень 45): найденные деньги +100%, коэффициент заданий +0.33.
Ранг 7 (уровень 53): найденные деньги +150%, коэффициент заданий +0.50.
Ранг 8 (уровень 61): найденные деньги +200%, коэффициент заданий +0.75.
Ранг 9 (уровень 69): найденные деньги +300%, коэффициент заданий +1.00.
Бонусы рангов итоговые. Сохраняется исходная схема заданий: прибавка
к коэффициенту награды экономической сложности, а не умножение выплаты.
Отдельная исходная интеграция Arti Lootboxes не изменена: +5% за ранг.
«Контрактник» удалён вместе с его отдельными обработчиками наград.
Experience Framework возвращает вложенные в удалённый навык очки
при загрузке сохранения штатным механизмом удаления отсутствующих навыков.

ОЧКИ НАВЫКОВ БЕЗ ПРЕСТИЖА
При престиже 0 уровни 10, 20, 30 и далее до 300 дают одно дополнительное
очко навыков. При стандартной базе 1 это 2 очка на каждом десятом уровне
и 1 очко на остальных. Бонус работает независимо от выключенной по
умолчанию опции дополнительных очков за престиж. При престиже выше 0
сохраняется исходный график и его переключатель.
Если базовое количество очков изменено, добавляется ровно +1, а не ×2.
Начисление происходит при получении уровня, включая несколько уровней
за одну награду опыта. Уже пройденные уровни автоматически не компенсируются.

ПЕРК «ВОЕННАЯ СХЕМОТЕХНИКА» — MILSPEC PDA
Один ранг с 90-го уровня. Открывает изготовление device_pda_milspec.
Оригинальный «413- Milspec PDA — Catspaw» должен быть установлен и включён:
его скрипты, конфиги предмета, иконки и остальные ресурсы сюда не включены.
Рецепт восстанавливается в списке UIWorkshopCraft после штатной загрузки
рецептов, в том числе если workshop_autoinject исключил его из списка.
Все прежние варианты изготовления этого предмета в этом меню заменяются
одним рецептом с отдельной проверкой изученного перка. Флешка не нужна
и не заменяет перк. Остальные рецепты и разблокировки не изменяются.
Состав взят из предоставленной версии Milspec PDA: экспертные инструменты,
ПДА 3.1, 20 транзисторов, 25 конденсаторов, 1 пластина K119 с углепластиком.
Штатная скидка достижения Artificer's Eagerness уменьшает большие количества
материалов на единицу. Наличие инструментов и расход компонентов проверяет
исходное крафтовое меню, сам интеграционный скрипт предметы не создаёт.
При сбросе навыка крафт блокируется; уже созданный ПДА не удаляется.
Собственная механика ПДА, режим слежения и ограничения фракций не меняются.
Если сторонний мод удалил саму секцию device_pda_milspec или использует
отдельное крафтовое меню вместо UIWorkshopCraft, нужна его адаптация.
Проверено скриптовыми тестами; проверка непосредственно в игре требуется.
