Absolute RPG v1.7.5 TEST

Навыки, особенности и задания для Anomaly / GAMMA / CLIKRAD.
Открытие: ПДА → Launcher MAC → Навыки и опыт.

УСТАНОВКА
1. Нужны Experience Framework 2.2c, Mod App Creator (MAC) и MCM.
2. Отключите предыдущую версию Absolute RPG и отдельные пакеты навыков,
   которые она заменяет. Установите этот архив целиком через MO2.
3. Разместите Absolute RPG ниже зависимостей, чтобы его файлы побеждали
   конфликты. Кэш личных настроек в архив не включён.
4. Выберите один вариант магазинного питания:
   GAMMA/No Mags; CLIKRAD без анимаций; CLIKRAD с анимациями.
5. При смене варианта удалите старую установку мода и установите новую,
   затем полностью перезапустите игру.

Для ручной установки скопируйте gamedata, затем содержимое gamedata
выбранного варианта из variants поверх неё. Для GAMMA/No Mags второй шаг
не нужен.

ЗАВИСИМОСТИ НАВЫКОВ
Необязательные моды устанавливаются отдельно. Если навык требует другой
мод или имеет ограничение, об этом написано красным в его описании.
Для встроенных навыков «Симбиоз» и «Егерь» отдельные Artefact Limb Healing
и Dorn's Faster Skinning включать не нужно; отключите их, чтобы избежать
наложения эффектов.

ИЗМЕНЕНИЯ 1.7.5
Единый формат описаний на русском и английском: краткое описание,
эффекты текущего ранга, затем требования и предупреждения красным.
Убраны дубли строк, устаревшие подсказки и старые названия в интерфейсе.
Игровая механика, требования уровней и стоимость навыков не изменены.

СТАТУС
Тестовая сборка. Выполнены автоматические проверки файлов и локализации.
Проверка отображения и работы в игре требуется.
