# Absolute RPG

Система навыков, особенностей и заданий для S.T.A.L.K.E.R. Anomaly / GAMMA / CLIKRAD.

**Текущая версия: 1.7.5 TEST.** Сборка требует проверки в игре.

- 66 навыков, 224 ранга.
- Окно навыков в ПДА через Launcher MAC.
- Русская и английская локализации.
- Три варианта магазинного питания: GAMMA/No Mags, CLIKRAD и CLIKRAD с AML.

## Установка

Скачайте установочный ZIP в разделе Releases и установите его через MO2.
Архив исходников GitHub не является установочным пакетом.

Обязательны Experience Framework 2.2c, Mod App Creator и MCM.
Absolute RPG должен побеждать конфликты файлов зависимостей.
Подробности установки — в `README_RU.txt`; требования отдельных навыков
указаны красным в игре.

## Проверки и сборка

Требуется Python 3.10 или новее, без дополнительных пакетов.

```text
python -m unittest discover -s tests
python tools/build_release.py
```

Проверки файлов не заменяют запуск в игре. Папки `tests` и `tools`
в установочный ZIP не включаются.
